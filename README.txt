GMA_OS v5.0 — regalo digital por cinco meses

CÓMO PROBARLO
1. Descomprime gma_os_5_meses.zip.
2. Abre la carpeta.
3. Haz doble clic en index.html. Se abrirá en tu navegador.

CÓMO PONER VUESTRAS FOTOS
1. Entra en la carpeta fotos.
2. Copia tus imágenes ahí y usa estos nombres:
   - foto-principal.jpg
   - recuerdo-1.jpg
   - recuerdo-2.jpg
   - recuerdo-3.jpg
   - recuerdo-4.jpg
3. Si tus fotos son PNG, cambia también la extensión en index.html.

CÓMO PERSONALIZAR
- Puedes cambiar los nombres, la carta y el texto del aniversario desde “Personalización rápida” dentro de la web.
- Para dejar tus cambios guardados de forma permanente, abre index.html en VS Code y modifica los valores de los campos y el texto de la carta.
- Los textos de “Recuerdos que quiero guardar” están dentro de <ul id="memoryList">.

CÓMO PUBLICAR GRATIS
Puedes usar GitHub Pages:
1. Crea un repositorio nuevo en GitHub.
2. Sube index.html y la carpeta fotos.
3. En Settings > Pages, activa la publicación desde la rama principal (main).
4. GitHub te dará un enlace para enviarle a Gma.

PRIVACIDAD
Si subes la página a un sitio público, cualquiera que tenga el enlace podría verla. Evita poner datos personales sensibles. Usa fotos que ambos estén cómodos compartiendo.
